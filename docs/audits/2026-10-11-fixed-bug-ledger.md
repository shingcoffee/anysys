# Consolidated fixed-bug ledger — 2026-10-11 audit

Consolidated and source-reconciled on 2026-10-12 at the user's request; the original audit filename is retained. **238 distinct production-source bug roots are recorded below.** These are source remediations in the current working tree, not 238 independently runtime-certified fixes or a passing release gate. The stable ledger IDs (`B01`, `A01`, etc.) are identifiers for this document; the trace column identifies the original findings without inventing original audit IDs. The 236-entry ledger contained neither the preview lifecycle root nor the advanced-unpaid-period preflight root: **W09 and X08 add exactly two distinct roots**. W01–W08 and X03–X07 retain their existing identities.

Each row records the root cause, observable impact, implemented correction and principal repository-relative code paths. Related F/RC/backend/integration findings are consolidated into one row when they describe the same root. A multi-part original finding can appear in multiple rows when its underlying defects differ. Listing an original ID does not assert that every observation or limitation in that finding was remedied.

Fixture, mock, selector, expectation, test-only storage isolation, lint-only and reporting repairs are excluded from the production-bug count. Historical unsubscribe-token compatibility is intentionally not implemented and is not counted as a fix. Unsupported base-model writes and unsupported Aliyun email capabilities are counted for their **explicit controlled rejection**, not as implemented capabilities.
