# Conditional Rules & Calculated Fields Drawer Redesign — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the full-screen-overlay + centered-modal UX for Conditional Rules and Calculated Fields on the page editor with a unified, right-docked slide-over drawer (master→detail), modernizing visuals and the build experience with zero loss of existing functionality.

**Architecture:** A shared `PageBuilder::BuilderDrawerComponent` provides accent-themed chrome (header / scrollable body / sticky footer) and hosts a **list** state and an **editor** state with an animated master→detail slide. The Rules and Calculations panels/editors are restyled to live inside this drawer. Existing Stimulus controllers (`page_builder`, `rules_manager`, `calculations_manager`, `rule_builder`, `formula-editor`) are reused — only their open/close/mount wiring and inline-HTML strings change, not their business logic. No schema, route, or auth changes.

**Tech Stack:** Rails 8.1 / ViewComponent / TailwindCSS (only) / StimulusJS (only) / RSpec.

```ruby
# app/components/page_builder/builder_drawer_component.rb
# frozen_string_literal: true

module PageBuilder
  class BuilderDrawerComponent < ApplicationComponent
    include DesignTokens
    include ComponentClasses

    ACCENTS = {
      indigo: { ring: "focus:ring-indigo-500", text: "text-indigo-600", soft: "bg-indigo-50", icon: "text-indigo-600" },
      purple: { ring: "focus:ring-purple-500", text: "text-purple-600", soft: "bg-purple-50", icon: "text-purple-600" }
    }.freeze

    def initialize(key:, title:, subtitle:, accent: :indigo, icon: :rules)
      @key = key
      @title = title
      @subtitle = subtitle
      @accent = accent.to_sym
      @icon = icon.to_sym
    end

    private

    attr_reader :key, :title, :subtitle, :accent, :icon

    def accent_classes
      ACCENTS.fetch(accent, ACCENTS[:indigo])
    end
  end
end
```
