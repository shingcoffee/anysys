# Entity Sharing Scope Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `Entity` a Customer Specific / Shared sharing scope (mirroring `Flowchart`), where shared entities are cross-tenant and only the platform owner can create/edit them, set via a Type selector under `/:cid/admin/maintenance/entities`.

**Architecture:** Rename the existing `entities.element_type` string column to a `type` integer enum `{ customer_specific: 0, shared: 1 }` identical to `Flowchart`. Shared entities have `customer_id NULL`, surface through an `accessible` scope, and are guarded owner-only in the controller. The form Type selector renders only for the platform owner.

**Tech Stack:** Rails 8.1, ActiveRecord enums, RSpec, FactoryBot, Tailwind, ViewComponent.

**Spec:** `docs/superpowers/specs/2026-06-28-entity-sharing-scope-design.md`

```ruby
# frozen_string_literal: true

class ReplaceEntityElementTypeWithType < ActiveRecord::Migration[8.1]
  def up
    add_column :entities, :type, :integer, null: false, default: 0
    add_index  :entities, :type

    # Every existing entity is a customer-specific "custom" entity → 0.
    execute "UPDATE entities SET type = 0"

    remove_index  :entities, :element_type
    remove_column :entities, :element_type

    # Shared entities carry NULL customer_id.
    change_column_null :entities, :customer_id, true
  end

  def down
    change_column_null :entities, :customer_id, false
    add_column :entities, :element_type, :string, null: false, default: "custom"
    add_index  :entities, :element_type
    execute "UPDATE entities SET element_type = 'custom'"
    remove_index  :entities, :type
    remove_column :entities, :type
  end
end
```
