# Email list Status removal + Dynamic Segment preview — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove `Emails::Audience::List` Status entirely, and add an explicit Preview on create/edit that runs unsaved Dynamic Segment rules through `SegmentQuery` into a paginated contacts table.

**Architecture:** Drop `email_lists.status` (migration + callers). Add collection `POST …/lists/preview` that parses `segment_rules_json`, runs `Emails::Audience::SegmentQuery`, paginates via `ModuleEntriesResolver`, and renders HTML into Turbo Frame `email_list_preview`. Stimulus `email-list-form` submits Preview (and pagination) as POSTs carrying the live builder JSON so create works before save.

**Tech Stack:** Rails 8.1 / Trailblazer-free for this slice / ViewComponent `AdminTableComponent` / Stimulus / Turbo Frames / RSpec / Vitest

**Spec:** `docs/superpowers/specs/2026-07-24-email-list-status-removal-and-segment-preview-design.md`

## Global Constraints

- No hard-coded user-facing strings — `en` + `zh-CN` for every new key; English value byte-identical to what would have been hard-coded.
- Stimulus: no literal UI strings in JS — English `default:` Values + server `data-*-value` when needed.
- Multi-tenant: preview relation always via `current_customer` / `SegmentQuery` tenant root.
- Auth: lists preview uses the same admin/owner + email campaigns guard as other lists actions.
- JS under `app/javascript/**` must stay at 100% Vitest lines + branches for touched files.
- Do **not** commit unless the user explicitly asks (repo policy). Skip commit steps or stage only.
- No Status/archive replacement; no show-page member browser; no auto-debounced preview.

- [ ] **Step 5: Controller `#preview`**

Add to `ListsController`:

```ruby
def preview
  rules = parse_preview_rules
  return render_preview_malformed if @segment_rules_error

  scope = ::Emails::Audience::SegmentQuery.call(customer: current_customer, rules: rules)
           .order(:email)

  @columns = [
    { key: :email,      label: I18n.t("common.labels.email"),      sortable: true, searchable: false },
    { key: :first_name, label: I18n.t("common.labels.first_name"), sortable: true, searchable: false },
    { key: :last_name,  label: I18n.t("common.labels.last_name"),  sortable: true, searchable: false }
  ]

  result = ModuleEntriesResolver.call(
    scope:   scope,
    columns: @columns,
    params:  params.permit(:page, :per_page, :sort, :dir).to_h.symbolize_keys
  )
  @rows           = result[:rows]
  @pagination     = result[:pagination]
  @match_count    = result[:pagination][:total]
  @preview_rules_json = rules.to_json

  render partial: "preview", layout: false
end

private

def parse_preview_rules
  raw = params[:segment_rules_json]
  return {} if raw.blank?

  JSON.parse(raw)
rescue JSON::ParserError
  @segment_rules_error = true
  {}
end

def render_preview_malformed
  @preview_error = t("admin_modules.emails.lists.preview.malformed")
  render partial: "preview", layout: false, status: :unprocessable_entity
end
```

Keep `parse_preview_rules` / `render_preview_malformed` private next to existing private methods. Do **not** call `load_list` for preview.

import { Controller } from "@hotwired/stimulus"

export default class extends Controller {
  static targets = ["panel", "previewFrame", "previewButton", "previewRules"]
  static values = {
    listType: { type: String, default: "dynamic" },
    previewUrl: { type: String, default: "" },
    loadingLabel: { type: String, default: "Loading..." }
  }

  connect() {
    this.apply(this.listTypeValue)
  }

  toggle(event) {
    this.apply(event.target.value)
  }

  apply(listType) {
    this.listTypeValue = listType
    this.panelTargets.forEach((el) => {
      el.classList.toggle("hidden", el.dataset.listType !== listType)
    })
  }

  preview(event) {
    event?.preventDefault?.()
    return this.#loadPreview(1)
  }

  previewPage(event) {
    event?.preventDefault?.()
    const page = event?.params?.page || event?.target?.dataset?.page || "1"
    return this.#loadPreview(page)
  }

  // Intercept GET pagination links rendered inside the preview table frame.
  interceptPreviewNav(event) {
    const anchor = event.target.closest?.("a[href]")
    if (!anchor || !this.hasPreviewFrameTarget) return
    if (!this.previewFrameTarget.contains(anchor)) return

    event.preventDefault()
    const url = new URL(anchor.href, window.location.origin)
    const page = url.searchParams.get("page") || "1"
    return this.#loadPreview(page)
  }

  async #loadPreview(page) {
    if (!this.previewUrlValue || !this.hasPreviewFrameTarget) return

    const rules = this.#currentRulesJson()
    const body = new FormData()
    body.set("segment_rules_json", rules)
    body.set("page", String(page))

    if (this.hasPreviewButtonTarget) {
      this.previewButtonTarget.disabled = true
      this.previewButtonTarget.dataset.originalLabel = this.previewButtonTarget.textContent
      this.previewButtonTarget.textContent = this.loadingLabelValue
    }

    try {
      const response = await fetch(this.previewUrlValue, {
        method: "POST",
        headers: {
          Accept: "text/html",
          "Turbo-Frame": "email_list_preview",
          "X-CSRF-Token": this.#csrfToken()
        },
        body,
        credentials: "same-origin"
      })
      const html = await response.text()
      this.#replaceFrame(html)
    } finally {
      if (this.hasPreviewButtonTarget) {
        this.previewButtonTarget.disabled = false
        if (this.previewButtonTarget.dataset.originalLabel) {
          this.previewButtonTarget.textContent = this.previewButtonTarget.dataset.originalLabel
        }
      }
    }
  }

  #currentRulesJson() {
    if (this.hasPreviewRulesTarget && this.previewRulesTarget.value) {
      // Prefer live builder input when present
    }
    const live = this.element.querySelector('[name="email_list[segment_rules_json]"]')
    if (live?.value) return live.value
    if (this.hasPreviewRulesTarget) return this.previewRulesTarget.value || "{}"
    return "{}"
  }

  #csrfToken() {
    return document.querySelector('meta[name="csrf-token"]')?.content || ""
  }

  #replaceFrame(html) {
    const doc = new DOMParser().parseFromString(html, "text/html")
    const next = doc.querySelector("turbo-frame#email_list_preview") || doc.body
    this.previewFrameTarget.replaceWith(next)
    // Re-bind: after replaceWith, target reference is stale — Stimulus reconnects if
    // the new frame stays inside this.element. Prefer:
    // this.previewFrameTarget.innerHTML = next.innerHTML when keeping the same node:
  }
}
