## 开始前

本组织需要启用网站模块。以管理员身份登录，确认有**内容 → 网站页面**和**设置 → 网站**。没有模块或站点时，请联系支持团队。

准备好审核通过的文案、图片和链接目标。您可以编辑本组织的网站内容和外观。预置页面布局决定区块类型和顺序；需要调整结构时，请联系支持团队。

## 操作步骤

### 编辑页面

1. 打开**内容 → 网站页面**，选择页面进行编辑。新增页面时，点击**新建页面**，选择可用布局，填写页面信息，然后点击**创建页面**。
2. 在页面设置中核对标题和网址标识。内页标识使用小写字母、数字和连字符，例如 `about`。修改后页面地址会变化，请更新使用旧地址的链接。
3. 编辑各区块提供的文案、链接和列表项。例如，更新开场标题和联系方式。站内链接可使用页面选择器，外部链接使用 `https://` 地址。
4. 在布局提供图片的位置添加或替换照片。可上传不超过 8 MB 的 JPEG、PNG、WebP 或 GIF 文件，也可使用 HTTPS 图片链接。
5. 分别检查**手机**、**平板**和**桌面**预览，核对文字长度、图片及按钮目标。
6. 点击**保存**并等待成功提示。重新打开编辑器核对文案；未保存的预览不代表页面已保存。

### 发布页面并设置导航可见性

1. 打开页面编辑器中的**页面设置**。
2. 为访客应能访问的页面勾选**已发布**。
3. 仅当页面应出现在站点菜单中时，勾选**显示在导航中**。例如，路径为 `about` 的页面可以已发布，但不显示在导航中。
4. 点击**保存**，返回网站页面列表核对**已发布**，再重新打开**页面设置**确认导航选项已保存。

:::note
**保存**用于持久保存页面内容与设置；页面的**已发布**决定其是否具备公开访问条件，站点的**公开网站**决定站点是否开放。两项发布设置均需保存。隐藏导航项不会阻止通过地址访问已发布页面。
:::

### 发布站点

1. 打开**设置 → 网站**，检查网站名称、标语、颜色模式、强调色、字体风格、间距、搜索展示信息、页脚及新页面的默认布局。
2. 点击**保存**。更改默认布局不会重构已有页面。
3. 在**发布设置**区域开启**公开网站**，点击**保存**，再核对已保存的发布状态。

![未发布的网站设置，公开网站开关关闭，并显示保存操作。](/help/docs/screenshots/zh-CN/website-publishing.png "站点公开选项需保存；各页面也须已发布，访客才能访问。")

### 以访客身份检查站点

1. 返回网站页面，点击**查看网站**。
2. 在未登录的浏览器中打开地址，核对首页、菜单、页脚和表单链接。
3. 若已发布 `about` 页面，直接打开其地址。确认隐藏的导航项未出现在菜单中，但已发布页面的地址仍可访问。
4. 页面无法打开时，先核对页面已保存的**已发布**选项和站点已保存的**公开网站**选项，再分享地址。

### 仅在确需替换时更换初始模板

:::attention
替换会永久删除现有页面和区块，重置外观及默认布局，并丢弃未保存的设置。替换后的页面尚未发布。操作前请另行保留所需文案；此操作不可撤销。
:::

1. 在网站设置中打开**起步模板 → 选择替换模板**。
2. 查看包含的页面。仅在确需执行上述替换时选择**替换网站**，并阅读确认提示。
3. 核对替换后的页面与外观。编辑、保存并发布新页面后，访客才能按发布条件访问。

## 预期结果

站点公开时，访客可浏览已发布页面。隐藏导航项不会阻止访客通过页面地址访问。首页不能删除。联系信息区块用于展示信息；需要收集提交内容时，请链接到可用表单。

## 常见问题

- **访客无法找到页面：**检查站点和页面的发布开关，以及当前网址标识。
- **预览与网站不同：**保存编辑后，重新打开公开页面。
- **图片无法显示：**检查文件格式、大小或 HTTPS 地址。
- **需要不同的布局区块：**向支持团队提供页面名称和期望结构。
