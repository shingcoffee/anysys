## 开始前

本组织需启用短信模块。以管理员身份登录，确认有**通信 → 短信**。发送服务需要经批准的发送方和模板，由服务团队安排。

确认收件人已同意接收此类消息。营销短信须在短信联系人上单独记录实际授权，填写凭证来源及同意内容。添加号码、同步数据或匹配受众均不授予许可；号码未在退订名单中不代表同意，新记录同意也不解除已有阻止。

在**设置 → 短信限额**查看每日发送额度。客户管理员只能查看，不能修改。需要调整额度或新增获批模板时，请联系支持团队。

短信工作区默认打开**活动**，可进入**联系人**、**分群**、**短信记录**及**退订记录**。活动按**受众 → 内容 → 发送时间 → 确认**配置已审核营销模板的个性化内容。模板文案与发送账户由服务团队管理，活动表单不能发送任意自由文本。事务短信也可由支持短信的已配置任务或表单发送。

## 操作步骤

### 添加联系人并单独记录授权

1. 打开**短信 → 联系人 → 添加联系人**，填写号码和两位国家代码（如 `CN`），可选姓名及 IANA 时区（如 `Asia/Shanghai`）。国家代码不决定时区，联系人时区为空时采用活动时区。
2. 按需填写**自定义属性（JSON）**，例如 `{"city":"Shanghai","vip":true}`。最多 32 个标量属性，总计 8 KiB，键以小写字母开头，不支持嵌套对象或数组。
3. 选择**保存联系人**。新联系人营销授权为未知，不代表可发送。
4. 打开联系人，单独记录授权事件。**记录同意**须填写凭证来源、收件人实际同意内容及发生时间，如 `2026-10-13T10:00:00+08:00`；必须含明确时差，不能为未来时间。**撤回同意**须填写凭证来源，两种操作均可附备注。
5. 查看**授权历史**与**发送资格**。事件仅追加，后续更正须另记事件。撤回还会阻止本组织向该号码发送；记录同意不解除组织／服务范围退订。

更换号码后，营销授权重置为未知，即使替换号码曾有历史证据，也须为该号码重新记录许可。旧证据仍对应旧号码。**归档联系人**保留证据及活动历史，并使其不可发送；**恢复联系人**不会自动补充同意或解除阻止。

### 预览并手动从实体同步联系人

1. 在**联系人**中选择**从实体同步**，选择可访问的受支持实体，再选择**加载字段**。仅支持普通实体记录，不支持原生模型扩展或桥接来源。
2. 选择实际的**电话字段**、可选**姓名字段**、国家及时区。仅命名为“电话”的字段不足以作为来源。可使用共享定义，但仅读取本组织的记录。
3. 可将联系人属性映射至实体标量字段标识，例如 `{"city":"city","vip":"vip"}`，不会导入授权字段。
4. 选择**预览前 100 条**，核查预计创建／更新／无变化、无效号码及来源／身份冲突。预览不修改数据。
5. 选择**同步此批次**，应用最多 100 条。有剩余记录时，使用**预览下一批 100 条**，确认后再手动同步。继续操作保留首次记录上界，不会将后来新增的来源记录静默纳入本轮。
6. 核查各批结果，解决冲突，并单独记录同意。这是明确的数据操作，不是定时后台同步。

同号更新保留已有同意，换号重置同意。同步更新映射属性，保留未映射属性与归档状态；来源／身份冲突按项报告，不合并。删除来源记录不会静默移除联系人，重跑批次也不授予许可。

### 定义并预览动态受众

1. 打开**短信 → 分群 → 创建分群**，命名后添加联系人字段或标量自定义属性条件。
2. 明确设置 AND／OR 及嵌套组。未分组时按从左到右计算；空根组考虑本组织全部联系人，仍须满足授权与发送资格。
3. 选择**预览受众**，比较**匹配联系人**、**当前可发送**、排除原因及样本。匹配可能包含已归档或未授权联系人，不代表获得许可。
4. 选择**保存分群**。名单动态匹配，不是固定保存的列表。被活动草稿引用的分群须先处理引用，才能删除。

无效规则一律拒绝，不会变成全部联系人。混合类型自定义属性不可用于受众字段。活动最多匹配 10,000 个联系人，超限须缩小分群。

### 配置内容与发送限制

1. 打开**短信 → 活动 → 创建活动**并命名。在**受众**选择已保存分群或**全部联系人**，授权与资格检查仍生效。
2. 在**内容**选择**已审核营销模板**，准确映射全部必需变量。可使用带显式默认值的联系人字段、固定值或服务器生成的签名退订链接。请将示例键替换为模板实际变量：

   ```json
   {
     "name": { "source": "field", "field": "name", "fallback": "Customer" },
     "offer": { "source": "literal", "value": "20%" },
     "opt_out_url": { "source": "field", "field": "unsubscribe_url" }
   }
   ```

3. 允许字段为 `name`、`phone_e164`、`country_code`、`timezone`、受控 `attributes.<key>` 及 `unsubscribe_url`，不执行代码或表达式。字段缺失／空白时使用显式默认值，没有默认值则跳过该收件人。无变量模板使用 `{}`。请服务团队确认实际获批内容包含有效退订通道或受支持回复说明。
4. 选择**示例联系人**，再选择**预览活动**以更新样本与人数。选样本不会将其加入受众，也不绕过授权。正文／段数预览取服务团队维护的可选审核内容副本；无副本时仅显示变量，正文／段数未知。预览不发送测试短信、不保存修改、不预留额度。
5. 在**发送时间**选择**立即发送**或**定时发送**。定时须填写本地日期／时间及 IANA 时区，修正夏令时不存在或有歧义的时间。
6. 设置限制，再选择**保存草稿**：

   | 限制 | 含义 |
   | --- | --- |
   | 免打扰时段 | 本地起止小时，默认 21:00–09:00，包含开始、不含结束，起止须不同。优先用收件人当前时区，否则用活动时区；仅等待至截止时间前。 |
   | 频次窗口 | 1–168 小时，默认 24。同组织同号码在窗口内最多尝试一次活动短信，未知结果的尝试也计入；达到限制即跳过，不承诺稍后重试。 |
   | 发送速率 | 每分钟 1–60 人，默认 60，限制活动接收速率；其他流量及共享账户上限可进一步延迟派发。 |
   | 有效时长 | 1–168 小时，默认 24，从预定开始计算，不从每个收件人入队起算；免打扰及其他延迟不重新计时。 |

安排模板、补全映射或选择定时时间期间，可保存未完成草稿。共享账户默认每秒授权一次发送尝试，服务团队可设得更低；所有组织、活动及直接发送共用，不保证手机送达速度。每日／号码额度仍生效。

### 确认已保存草稿并单独启动

1. 打开已保存草稿，核对**已保存活动设置**、当前人数、排除项、等待联系人、个性化样本、预定开始、绝对截止时间及预估最短时长。时长只是下界，不是送达承诺。
2. 处理**启动前须处理**项，例如营销内容缺失、映射不完整、没有已同意且可发送联系人、发送账户不可用或定时时间已过。保存修改后重新预览。
3. 按需在已保存草稿选择**预览活动**以刷新确认，再选择**启动活动**或**定时发送**。确认授权有效 15 分钟；已保存设置、受众规则、模板内容或所选账户身份变化会使其失效。收到提示时重新刷新／确认。
4. 跟踪活动详情及**查看报告**。已启动活动不能编辑或重新启动；草稿可删除，已启动活动及报告保留。

:::attention
启动固定规则、模板内容及设置；实际执行开始时才一次性捕获受众。确认至开始之间的联系人变化可改变名单。开始时为全部匹配联系人（含排除者）固定目标、个性化与资格，之后补录同意／恢复不会加入初始排除者。后续换号、归档、撤回或退订可阻止剩余发送，但不替换冻结内容或目标。
:::

### 取消剩余发送并查看报告

1. 活动待发送或发送中时，如需停止，选择**取消剩余发送**。待处理收件人及未尝试的关联排队消息会关闭，重复取消无额外影响。已尝试消息不能撤回，仍继续更新投递结果。
2. 打开**查看报告**，比较匹配／开始时可发送、待处理／已入队、已尝试／服务商已受理及当前送达结果，分别查看终止原因与当前延迟。
3. 按收件人／消息状态、原因或姓名／号码筛选，打开关联消息排查。选择**下载 CSV**导出全部筛选收件人，不仅当前页；包含目标、状态、时间、失败代码及服务商实际段数，表头本地化，不含变量值、授权证据、原始响应或签名链接。
4. **已完成**表示派发处理结束，不表示每部手机均确认收到。已尝试与服务商已受理是历史节点，与当前投递结果重叠，不可相加。送达率为已送达除以已尝试，尚无尝试时未知。服务商段数仅汇总已报告事实并展示缺失数，不作费用报价。

收件人打开签名退订链接后先看到掩码号码确认页，只有选择**确认退订**才记录撤回及组织范围阻止，仅打开链接不会退订。链接有效期 365 天；换号后的旧链接仍对应原号码，不影响替换号码。

### 准备并执行约定测试

1. 请配置负责人确认由哪个表单或任务发送短信，以及使用哪个获批模板。
2. 准备任务输入：
   1. 使用约定收件人，例如团队能访问的手机，用于核查确认短信。
   2. 国际号码以 `+` 或 `00` 开头；任务采用默认国家上下文时，也可使用有效中国本地号码。可用空格、连字符及配对括号格式化号码，不要附加说明文字或分机。其他本地号码格式请向配置团队确认。
   3. 只填获批模板要求的值，例如模板需要预约日期时提供该日期。不要添加无关字段或嵌套列表／对象。
3. 使用任务实际的提交操作执行一次。这会接收真实短信供后台发送，不是预览；任务还可能创建记录或收款。
4. 先阅读任务完成提示或错误，再查看日志。任务成功或消息排队，不代表手机已经收到短信。

### 查找消息并核对回执

1. 打开**通信 → 短信**，再进入**短信记录**，或进入**模块 → 短信 → 短信记录**。
2. 按收件人号码或获批模板标识搜索。例如，粘贴任务中使用的同一号码；无匹配行时清除搜索。
3. 按可排序列及分页查找对应时间，再打开消息。
4. 对照原任务输入，核对目标号码、模板、厂商、状态及厂商消息编号。详情展示变量名，但所有值均隐藏，请回到原任务核对。查看派发开始、尝试次数、发送／送达时间、到期时间、厂商事件时间／状态及实际报告的分段数。失败消息可查看**失败**代码／文本；缺少的事实显示未知或未记录。同时检查团队测试手机与记录状态。
5. 保留消息编号和结果供支持团队排查。重复原任务前，请先确认当前结果。

### 查看退订

1. 打开**模块 → 短信 → 退订名单**。
2. 搜索收件人号码，核对**原因**和**范围**。列表可能同时包含本组织及整个服务范围的阻止记录。
3. 尊重退订选择。不要通过改变号码格式或改用其他任务来绕过阻止规则。认为记录有误时，请提供收件人相关情况，由支持团队核查。

已验证的 STOP 回复（包括 REVOKE／OPTOUT 或厂商的 STOP 分类）及 Twilio 错误 `21610` 可创建服务范围的全局阻止。START／HELP 回复不会在 Anysys 中自动解除该阻止或记录重新许可。名单仅展示本组织实际联系过的号码所对应的全局阻止；接收时被阻止的消息不会暴露其他组织的退订历史。

## 预期结果

| 状态 | 含义 |
| --- | --- |
| 排队中 | 任务已记录消息，等待后台派发。 |
| 待处理 | 历史记录仍未决，不是新发送的初始状态。 |
| 已发送 | 发送服务已接受消息，不证明手机已收到。 |
| 已送达 | 投递回执确认成功。 |
| 失败 | 厂商拒绝发送或报告投递失败。 |
| 未知 | 接受或投递结果不确定，不意味着允许重发。 |
| 被阻止发送 | 外部尝试前被阻止。 |
| 已到期 | 发送尝试前超过截止时间。 |

直接／任务发送默认在接收后一小时截止，已配置任务可采用其他期限；活动按预定开始计算绝对截止时间。派发前停用短信或收到退订，可阻止已经排队的消息；营销还会检查当前联系人状态、号码与同意。一旦开始尝试，服务不会自动再次发送同一消息，即使超时或缺少回执。迟到回执可将未知或失败记录修复为已送达。

消息记录完成写入的重试仅重复数据库写入，不重复发送短信。未知消息可保留部分或畸形应答中的可用厂商消息编号，供后续回执匹配或厂商查询；编号本身不证明接受或送达。厂商查询等待及超龄判断从派发起算，历史行回退至接受／创建时间，不以新任务提交时间起算。

实际分段数仅在厂商报告时显示。提供审核内容副本时，活动预览可估算渲染样本；仅凭厂商模板编号无法估算，分段信息也不是价格报价。

厂商事件时间可能是厂商资源更新时间，未知或失败消息也可有此时间。该时间戳或分段数不确认送达，应查看已送达状态及其回执。发送时间表示 API 接受，不表示手机收到。

获批模板需要填入相应的值。客户管理员在此查看结果；发送方审批和模板可用性由服务团队管理。

## 常见问题

- **联系人匹配但不能收营销短信：**检查同意、归档、换号、退订、个性化值缺失及活动频次。同步或新记录同意不解除阻止。
- **无法启动或确认已变化：**保存最新草稿、处理阻塞项并重新确认。无有效营销模板或已配置账户须请服务团队修复；未保存预览不能启动其修改。
- **活动等待中：**查看免打扰、活动／共享账户容量或每日／号码额度延迟。绝对截止时间仍生效，估算不保证完成时间。
- **取消或完成后仍有未决发送：**已尝试消息可收到迟到回执，无重发未知结果或撤回操作。请排查原消息，不要为获得更明确状态而启动重复活动。
- **没有消息记录：**检查任务完成提示，清除日志搜索，并查看对应时间。仍未出现时，先向支持团队提供任务名称、时间和目标模板，再决定是否重跑。
- **消息失败：**查看**失败**信息，按提示修正收件人或必需值；服务商／模板错误请联系支持团队。重试前，核对任务是否已经创建其他记录或收款。
- **持续排队：**核对截止时间，并请支持团队检查队列／任务恢复。重复任务可能新增消息及其他记录。
- **消息已到期：**请支持团队确认派发为何错过截止时间，以及此时发送新消息是否仍有意义，再决定是否重新提交。
- **状态为已发送或未知：**等待回执并检查测试手机；服务商接受消息或缺少回执，不等于已确认送达。回调缺失时服务可查询厂商，但部分结果仍会未决。不要仅为获得更明确的状态而重复不确定的发送。
- **被阻止发送：**核对退订情况，或请支持团队确认派发前是否停用了短信。START／HELP 回复不会自动解除阻止。
- **达到每日限额：**等待额度重置，或向支持团队申请调整。
- **短信、模板或发送凭证不可用：**向支持团队提供目标任务、模板及任务显示的本地化错误消息。缺少发送凭证时，须修复服务配置后才能将新的发送请求加入队列。
