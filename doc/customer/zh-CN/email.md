## 开始前

本组织需启用邮件模块，且发送服务已就绪。以管理员身份登录，在**设置 → 邮件限额**查看每日额度。该限额由服务团队管理；需要调整或发送服务不可用时，请联系支持团队。

准备好邮件内容，明确本组织中要联系的已有用户。首次发送建议使用可逐一核对的小规模名单。测试邮件同样使用发送服务，也可能受到限额或阻止发送规则的限制。

## 操作步骤

### 编写并测试模板

1. 打开**通信 → 邮件**，在模块侧栏选择**内容 → 模板**，点击**新建模板**。
2. 填写名称、主题和正文。例如，命名为 `Welcome email`，在主题中输入 `{{`，或在正文中点击**插入变量**，选择可用的名字变量。请使用选择器，不要自行编造变量名。可用字段在**设置 → 邮件个性化**中管理。
3. 点击**预览**，核对布局、链接、图片和纯文本备用内容。独立预览显示变量标签，不填入样例值。
4. 在**发送测试邮件**中填写您能访问的邮箱，点击**发送测试**。核对结果提示及该邮箱中的邮件；测试使用真实发送服务。

:::note
所有测试收件地址均使用当前登录管理员的个性化信息，而非目标邮箱所属用户的资料。例如，您的名为 Alex 时，即使测试发到他人邮箱，所选名字变量仍使用 Alex。真实发送活动则使用每位实际收件人的上下文。测试未保存内容不会保存模板；收件人与记录的关联功能尚未接入，发送邮件时自定义实体字段目前会留空。
:::

### 保存并启用模板

1. 创建模板时，若内容已就绪，请在提交前勾选**立即启用此模板**。
2. 点击**创建模板**或**更新模板**，保存已检查的内容。
3. 若已保存的模板尚未启用，待内容就绪后执行**设为启用**。
4. 重新打开模板，核对已保存内容及**已启用**状态。发送活动只提供已启用模板。

### 创建并核对受众列表

1. 打开**受众 → 列表**，选择**新建列表**。
2. 填写易于辨认的名称，例如 `Welcome test audience`，选择**类型**：
   1. **静态列表：**在**成员邮箱**中每行填写一个已有用户邮箱，例如本组织确有该账户时填写 `alex@example.com`。
   2. **动态细分：**设置**受众条件**，点击**预览**核对匹配用户。
3. 点击**创建**，同时阅读保存提示和未知邮箱警告。
4. 打开已保存列表，核对静态成员，或重新预览动态条件。仅向会员发送时，选入目标会员账户，或使用可用条件缩小范围并逐项核对匹配结果。

![新建邮件列表表单，已选择动态细分，并显示添加条件、添加分组、预览和创建控件。](/help/docs/screenshots/zh-CN/email-audience.png "在此设置并预览受众条件，再点击创建以保存动态列表。")

:::note
列表匹配本组织的已有用户，包括管理员账户；**成员邮箱**字段不会强制限定会员角色。静态列表会省略未知地址。动态条件在发送使用时重新计算，因此预览只反映当前匹配结果，不会冻结收件人名单。
:::

### 立即或定时发送

1. 打开**发送活动**，选择**新建发送活动**。
2. 依次完成向导步骤：
   1. **受众：**命名活动，在页面显示的选择上限内选取已核对列表。
   2. **内容：**选择已保存且已启用的模板。
   3. **计划：**选择**立即发送**或**定时发送**。定时发送需核对日期、时间和时区；单次发送保留**不重复**。
   4. **检查：**一并核对受众、内容和时间。同一收件人出现在多个所选列表中时，每次活动只收到一封邮件。

### 提交已检查的活动

:::attention
选择**立即发送**后，最终提交会将真实投递加入队列，并非仅保存草稿。已发送邮件无法撤回。提交前请确认受众与内容。
:::

1. 在**检查**步骤点击**创建**提交活动；编辑待处理活动时点击**更新**。有校验错误时，修正后再提交。
2. 打开已保存活动，核对名称、列表、模板、计划时间和状态。定时活动在处理开始前保持待处理状态；重试前请先确认状态。

### 查看投递或停止后续发送

1. 打开活动查看状态和投递数量。处理失败时，检查**失败原因**。
2. 配置需要调整时，在处理开始前编辑待处理活动。
3. 需要停止后续投递时，使用可用的取消操作并核对状态。取消不会撤回已发送邮件。

## 预期结果

活动状态记录处理和完成情况，投递数量则区分已发送、已送达、失败、退信和被阻止发送的邮件。活动成功不代表每个收件人都收到邮件。部分发送服务只报告**已发送**，不提供后续送达确认。

通过**分析**及其报告、送达率和互动标签查看结果。**受众 → 退信名单**显示被阻止发送的地址。尊重退订和投诉，不要为了强行重发而移除阻止规则。

## 常见问题

- **找不到模板：**保存内容，确认**已启用**，再在向导中点击**刷新模板**。
- **测试个性化显示您的名字：**这是预期行为，测试使用当前管理员资料。需核查收件人专属内容时，使用经明确审核的小规模真实活动。
- **静态名单遗漏地址：**检查提示，确认这些地址是否属于本组织的已有用户。
- **动态名单为空：**检查条件并重新预览。
- **发送失败或达到限额：**阅读失败原因，重试前检查活动状态，并联系支持团队。投递仍在处理时不要创建重复活动。
- **没有统计数据：**检查日期范围，并等待投递或互动事件更新。
