## 开始前

以管理员身份登录，打开**内容 → 表单**。表单是收集或展示信息的任务页面，与宣传网站页面分开管理。

先确认表单属于本组织，还是预置共享内容。您可以管理本组织表单的发布状态和访问对象。共享表单的名称、定义和发布由服务团队统一管理；需要变更时，请联系支持团队。

公开表单前，请明确访客可以查看和提交什么。公开访问无需登录；会员访问需要账户。

## 操作步骤

### 查找并查看表单

1. 打开**内容 → 表单**，在侧栏选择**全部表单**、记录类型分组或**未分类**。
2. 按名称搜索，例如 `Registration`，再通过**状态 → 已上线**或**草稿**缩小范围。
3. 打开该行的更多操作菜单，选择**预览**。检查标签、必填字段、说明和预期任务。预览页面布局不等于测试真实提交。
4. 选择**管理访问**，打开发布与访问对象面板，查看状态和各类访问链接。

![未上线表单的访问面板，包含上线及成员、公开可见性控件。](/help/docs/screenshots/zh-CN/forms-publishing.png "访问面板分别显示上线状态与访问对象可见性，分享前请核对两项。")

### 以管理员身份填写表单

1. 选择已上线表单的名称或其**填写**按钮，表单在管理后台内打开；如需保留列表，可在行菜单中选择**在新标签页打开**。
2. 填写字段并提交。保存成功后返回同一表单的空白页，可继续录入下一条。
3. 在列出记录的下拉框中，若所需记录尚不存在，选择**+ 新增**，在对话框中填写该记录并选择**创建条目**；对话框关闭后，新记录会被自动选中。选择**取消**或按 Esc 则保留原先的选择。

:::note
草稿及管理员不可见的表单显示**预览**而非**填写**。**+ 新增**仅对管理员显示，会员与公开访客看到的是普通列表。
:::

### 上线本组织的表单并选择访问对象

1. 在面板或行菜单中选择**上线**。若操作被拒绝，请阅读错误，并联系支持团队解决表单配置问题后再试。
2. 先确认面板显示表单已上线，再检查访问范围。
3. 设置访问对象：
   1. 保留始终包含的管理员访问。
   2. 面向已登录会员时开放会员访问；面向无需登录的访客时开放公开访问。
   3. 注意两项联动：开放公开访问也会开放会员访问；关闭会员访问也会关闭公开访问。
4. 等待每次访问对象变更自动保存。重新打开**管理访问**，确认选项已保留。

:::note
上线状态与访问对象是两项不同设置。访问开关自动保存，不会将离线表单上线。页面显示公开链接，本身不代表已开放访问。
:::

### 检查链接与真实提交

1. 使用对应访问对象的**打开**链接检查已上线表单。
2. 会员访问需用指定会员账户核查。管理员打开会员链接时仅能只读预览，不能测试会员写入操作。
3. 公开访问需复制显示的公开链接，在未登录的浏览器中打开。
4. 仅在确实打算创建或修改数据时提交约定样例。例如，注册任务可使用指定测试会员，不要提交他人的信息来预览效果。
5. 阅读完成提示或字段错误。任务会写入记录时，先检查目标记录列表，再决定是否重新提交。

### 撤回表单

1. 打开本组织表单的访问面板，选择**下线**。
2. 确认离线状态，并检查正常访问链接已无法使用。
3. 检查网站或邮件中指向该表单的链接，按需更新。

## 预期结果

已上线表单仍需配置正确的访问对象才能打开。仅显示公开链接并不代表已经开放公开访问。草稿或已下线的表单不能通过正常访问链接使用。

表单菜单用于查看和分发已有表单，不提供客户表单布局编辑器。需要新增字段或表单时，请向支持团队说明任务及访问对象。共享表单可用于本组织的数据，但其预置定义不由您管理。

## 常见问题

- **链接无法打开：**检查上线状态和访问对象，确认复制的是当前链接。
- **共享表单不允许变更：**请支持团队处理该预置表单。
- **提交失败：**记录字段错误，修正值，并确认上次提交结果后再提交。
- **公开请求受限：**在**设置 → 公开页面防护**查看本组织公开表单的限额。验证挑战配置或共享表单问题请联系支持团队。
