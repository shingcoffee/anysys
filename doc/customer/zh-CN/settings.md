## 开始前

以本组织管理员身份登录，打开**设置**，查看已启用模块、会员中心和服务账单的可用设置。可按页面显示的名称搜索所需任务。

客户设置仅影响本组织。部分值仅供查看或由服务团队管理。需要调整只读限额，或没有所需选项、模块时，请联系支持团队。

## 操作步骤

### 开放或暂停会员注册

1. 打开**设置 → 会员注册**。
2. 将**允许会员注册**设为**已启用**或**已停用**。例如，准备会员界面期间可保持停用。
3. 点击**保存**并核对选项。禁用期间，待确认注册链接和确认邮件重发请求也会暂停，直到再次启用。

### 允许或停用密码找回

:::attention
停用期间不会发送重置邮件，已发出的重置链接也无法使用。此设置影响本组织所有账户，包括管理员。保存禁用选项前，请安排其他账户恢复方式。
:::

1. 打开**设置 → 密码重置**，查看**允许密码重置**。
2. 选择**已启用**或**已停用**，点击**保存**。
3. 重新打开设置，确认已保存状态。启用后，需要找回密码的用户可从登录页申请新链接。

### 要求管理员使用双重身份验证

1. 打开**设置 → 账户安全**。
2. 将**要求双重身份验证**设为**是**，点击**保存更改**。
3. 核对已保存选项。管理员和所有者须完成 MFA 设置或验证后才能访问受保护页面；已登录但仍需完成设置的会话也适用。会员通过自己的安全设置自愿启用，此租户策略不会强制会员使用 MFA。
4. 需要核对访问范围时，查看**角色与权限**或**用户访问权限**。内置只读权限保持固定。

:::note
**会话超时时间（分钟）**和**锁定前允许的登录失败次数**目前只保存为偏好，登录防护尚未读取这些值。保存不会改变实际执行的超时或锁定阈值。需要核查实际登录行为时，请联系支持团队，不要依据这些值判断。
:::

### 选择会员可见内容

1. 打开**设置 → 会员中心**。
2. 选择**基础页面**、**会员模块**或**记录页面**。基础首页、个人资料和安全页面始终可用，不能隐藏或调整顺序。
3. 调整可选页面的会员可见性，变更会立即保存。显示页面不会让会员获得其他人的记录权限。
4. 打开页面的**展示设置**，调整所提供的导航文字、显示列、记录详情、空页面提示、图标或顺序。例如，将报名记录页的显示名称改为 `My enrollments`。点击**保存**以保存展示变更。
5. 使用指定会员账户检查结果，确认展示的是该账户自己的记录及预期服务。

### 查看模块偏好

1. 在**网站**管理外观和发布，在**AI 助手**选择语言偏好。
2. 在**邮件限额**和**短信限额**查看服务团队设定的每日额度，在**邮件个性化**管理可用邮件字段。
3. 在**收款服务商**管理收款配置，在**账单**分组管理 Anysys 套餐、付款方式和账单明细。

### 为本组织公开表单设置请求限制

1. 打开**设置 → 公开页面防护**，检查防护已停用、服务商已配置或暂不可用等状态。
2. 在**公开页面请求限制**中找到本组织的公开表单。预置共享表单单独管理，不能在此列表中编辑。
3. 选择预设，例如**每个 IP 每分钟 20 次请求**，预设立即保存。选择**自定义限制…**时，填写请求次数与时间范围，再点击**应用**。
4. 重新打开设置，核对已保存限制。通过**打开页面**，以未登录状态检查目标表单。

:::note
保存页面限制不会配置平台验证码密钥，也不能证明验证挑战可用。防护需要已启用模块及已配置服务商，请同时检查就绪状态和真实访客体验。服务商不可用或共享表单需要调整时，请联系支持团队。
:::

## 预期结果

注册、密码找回、管理员 MFA 和展示偏好需成功保存。会员可见性及公开表单限额预设立即保存；自定义限制需点击**应用**。超时和失败次数偏好仍受上述限制。模块可用性、发送／录音限额及共享定义由服务团队管理。

## 常见问题

- **找不到设置：**清除设置搜索条件，并检查已启用模块。
- **变更未保留：**确认保存成功，检查校验信息。
- **会员仍能看到基础页面：**基础页面不能隐藏。
- **防护设置没有某个公开表单：**确认它属于本组织的公开表单，而不是共享内容或网站页面。
- **没有出现验证挑战：**检查防护就绪状态及页面限制，再向支持团队提供表单名称和实际表现。客户设置不能修复服务商凭据。
