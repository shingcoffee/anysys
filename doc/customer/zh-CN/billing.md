## 开始前

以管理员身份登录，打开**设置**下的**账单**分组。此处管理的是本组织的服务订阅。

服务账单与支付模块分开管理，后者记录向客户或会员收取的款项。修改订阅或付款方式前，请先确认要核查的是哪类费用。

## 操作步骤

### 查看或更换套餐

1. 打开**设置 → 套餐**，查看当前订阅状态、价格、币种、计费周期、试用结束或续订日期，以及是否已安排取消。
2. 比较可用套餐：
   1. 核对计费价格、币种和周期。年度套餐的折合月均价格仅供比较，不表示按月扣款。
   2. 对照当前用量，比较实际执行的页面、实体和会员额度。付费额度按已受理的套餐快照计算；目录修改不会改变已购买的条款。
   3. 每位客户最多享有一次付费套餐试用。从免费套餐升级或切换套餐不会重新开始试用。
3. 首次或重新订阅时，打开**查看订阅详情**，核对条款后点击**订阅**。已有有效订阅时，选择**查看套餐变更详情**，核对服务器计算的费用及生效时间，再点击**切换**。同周期升级须先结清按比例计费账单，人工付款也不例外；降级、同价变更及周期变更在续订时生效，试用期变更在试用结束时生效。
   变更受阻时，详情会先说明原因；解决问题前，不会提供扣款估算、已确认的生效时间或提交操作。
4. 提交后核对已保存的请求。待付款的升级保留当前已购买套餐；原价大于零的新订阅在结清前适用免费套餐的有限额度。没有未解决的服务商付款阻止操作时，可取消待完成的变更；选择其他套餐前须先处理现有请求。
5. 有优惠码时，在**使用优惠券**或首次订阅确认区域填写**优惠券代码**。条款在兑换时保存；次数自关联起按符合条件的、原价大于零的首期及续订周期计算。免费及按比例计费账单不占次数，已出具的账单不变，作废账单不返还已用次数。

### 授权账单付款方式

1. 打开**设置 → 付款方式**，在**付款授权**区域点击目标服务商的**设置**按钮，按页面要求完成定期服务费授权。
2. 支付宝授权通过服务商跳转或表单完成，仅支持 CNY；Stripe 使用服务商安全银行卡表单。返回**已保存的账单付款方式**，同时核对状态和扣款就绪说明。仅有**已激活**状态，不代表服务商账户、币种及已核实授权均可用于扣款。
3. 通过**设为默认**选择已授权的账单付款方式，再核对默认标识。仍需自动扣款时，请勿移除唯一可用的方式。
4. 待授权、失败及已移除的方式仍会显示，每页显示 25 条，可通过翻页查看较早授权。**继续授权**打开现有待完成请求。移除后立即停止发起本地新扣款，服务商端的清理可能仍待完成。添加方式不会自动结清账单或恢复已结束的服务。

### 停止或恢复续订

1. 打开**设置 → 套餐**，选择**取消订阅**。
2. 阅读确认提示，仅在确需于当前周期结束时停止续订时确认。
3. 核对**计划取消日期**及所示日期。订阅不会立即结束。
4. 在取消生效前，选择**保留订阅**撤回取消安排。此操作不清偿欠款，也不恢复已取消的套餐变更。未结清账单仍需支付，取消订阅不代表退款。
   取消及保留操作按服务器核实的当前条件显示，包括付款冲突和取消生效时间；仅凭已保存的状态或取消标识，不能断定操作可用。

### 保存账单记录

1. 打开**设置 → 账单明细**，搜索账单编号或按状态筛选，通过翻页查看较早记录。每页显示 25 条。
2. 分别核对账单状态和**收款状态**，以及计费期间、到期日、已冻结的明细及总额、收款失败次数和下次计划扣款时间。处理中或待验证的付款不可另行发起扣款。
   标记为**无法收回**的账单，仍可能存在处理中的付款、待完成的验证或待核对的结算。请以实际收款状态为准，不能仅凭此财务分类认定收款重试已耗尽。
3. 使用**下载**打开可打印账单视图，或选择**打印**。浏览器支持时，可打印该视图或保存为 PDF。
4. 核对打开或保存的文档具有相同账单编号和总额。**下载**打开完整文档，不一定直接下载 PDF 文件。
5. 提供相关操作时，**支付账单**对原账单发起经授权的重试；**完成付款验证**确认原有 Stripe 付款。请刷新查看已核实的结算结果。可打印文档不包含付款组件或客户端密钥。

## 预期结果

可用的账单付款服务商和套餐由服务团队管理。客户管理员可恢复符合条件的账单付款；人工结算及收款规则覆盖仅限平台所有者操作。付费权益不可用或已保存的宽限期结束后，适用免费套餐的有限额度。现有记录仍可查看，但超额新增可能被阻止。服务已结束时，须明确重新订阅。

## 常见问题

- **没有套餐或付款服务商：**联系支持团队检查是否可用。
- **套餐变更被拒绝：**重试前请处理现有付款、套餐变更或取消安排冲突。每次提交时，服务器都会重新核对当前状态。
- **计费表单被拒绝：**请查看可跳转至字段的错误提示，并修正提交值。无效价格文本、空值、套餐额度及重试安排原文会保留，便于更正；被拒绝的表单不会覆盖已保存记录。
- **订阅逾期：**检查付款方式状态和账单，再向支持团队咨询未解决的扣款问题。
- **授权仍待确认：**再次授权前，先核对付款方式当前状态及服务商结果。待授权不代表已成为可用的默认付款方式。
- **费用有误或缺少较早账单：**请重置筛选、查看后续页面，再向支持团队提供账单编号及相关日期。请求结束或过期后收到的付款可能需由平台核对，不会直接恢复服务。
