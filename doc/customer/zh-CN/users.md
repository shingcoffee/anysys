## 开始前

以管理员身份登录，确认菜单中有**用户**。该功能需要启用用户认证模块。准备好姓名、邮箱和所需访问权限。

**管理员**管理本组织的资源；**会员**使用自己的账户、个人资料和会员记录。仅向确实需要承担管理职责的人授予管理员权限。服务所有者的保留权限不能分配给客户用户。

## 操作步骤

### 创建账户

1. 打开**用户**，或进入**模块 → 用户认证 → 用户**。
2. 选择**新建用户**，填写以下字段：
   1. 填写名、姓和邮箱。例如，仅当 `alex@example.com` 是该用户实际要使用的账户邮箱时，才填写此地址。
   2. 输入至少八个字符的密码，在**确认密码**中再次输入。
   3. 按职责选择**管理员**或**成员**（会员账户）。
3. 点击**创建用户**。出现校验错误时，修正标出的字段后再提交。
4. 搜索已保存的邮箱并打开账户，核对姓名、角色和状态。

:::note
管理员创建的账户会在创建时完成确认。创建账户不等于发送邀请邮件，请另行安排用户如何取得访问权限。会员自行注册由**设置 → 会员注册**单独控制。
:::

### 更新账户资料

1. 按姓名或邮箱查找用户，按需使用角色或状态筛选。
2. 打开账户，选择**编辑**。
3. 仅修改所需字段。保留原密码时，将密码和确认密码留空。修改自己的账户时，按提示填写当前密码。
4. 点击**更新用户**，重新打开详情，核对已保存的姓名、邮箱和角色。

### 停用或恢复访问

1. 在用户详情页查看角色、MFA 状态、登录活动和受信任设备。
2. 当用户不应继续登录时，选择**停用**；需要恢复访问时，选择**启用**。不能停用自己的账户。
3. 先核对操作后的账户状态，再通知用户重新登录。

### 重置 MFA 或撤销受信任设备

1. 打开用户详情。用户丢失身份验证器时，先核实身份，再点击**重置两步验证**并阅读确认提示。重置自己的 MFA 时，请另一位管理员协助。
2. 确认账户不再显示已完成 MFA 设置；需要双重验证时，用户须重新设置。重置不会改变角色。
3. 在**受信任的设备**中，针对不再使用或不认识的设备点击**撤销**。确认设备已从列表移除；下次从该设备登录时，若账户要求双重验证，须重新验证。
4. 打开**模块 → 用户认证 → 安全日志**查看登录和安全变更，按时间范围筛选，或按 IP 地址、设备搜索。

## 预期结果

变更仅作用于本组织的账户。停用会阻止登录，不会删除用户记录。MFA 和受信任设备操作改变登录防护，不改变访问范围。

内置角色有固定的访问范围。**设置 → 用户访问权限**和**角色与权限**可用于查看已有权限；只读权限不能在此修改。

## 常见问题

- **无法创建用户：**修正标出的字段，检查邮箱是否已被使用，并查看是否出现套餐限额提示。
- **用户无法登录：**先检查账户状态、注册或找回密码设置及 MFA 要求，再考虑是否需要调整角色。
- **修改自己的邮箱或密码失败：**按提示填写当前密码。
- **没有用户菜单：**联系支持团队检查模块是否可用。
