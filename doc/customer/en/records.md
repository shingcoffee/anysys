## Before you start

Sign in as an administrator. **Domains** is the menu for record types available in your workspace, such as a Student record type if your organization uses one. The names and fields depend on your setup.

A record type describes the information collected; its entries are your organization's actual records. A supplied shared record type can be available to several organizations, but the entries you browse here belong to your own organization.

## Steps

### Find an entry

1. Open **Domains**. The sidebar lists every business domain, such as Academics or Sales, with its record types. The page opens on the first domain; select another domain in the sidebar to show its record types. Choose a record type on the page or in the sidebar.
2. Enter a value in **Search entries…**. For example, search `Alex` when a name field is available, or `alex@example.com` when email is searchable. Use the filters offered for this record type.
3. Select a sortable column heading to change the order. Use pagination to move through the results.
4. Check that the results match the query and selected record type. Clear search if you need the full list again.

![Record list with search, column selection, and CSV export controls.](/help/docs/screenshots/en/records-list.png "Use search to find entries and the list controls to choose the fields you review.")

### Review details or change information

1. Open the intended entry to display its detail panel.
2. Compare full field values and the entry reference, especially if several people have the same name.
3. To add or update information, use a task-specific form under **Content → Forms**. The list is a review surface, not a spreadsheet editor. Ask support if the needed form is unavailable.
4. After a real form submission succeeds, return to this record type and reopen the entry to check the changed values.

### Choose visible columns

1. Select **Columns** to choose the fields shown in the list. Adjust page size or density using the list controls when needed.
2. Check that the selected columns appear. Hiding a column leaves its data intact and does not change the form's fields.

### Export matching entries

1. Apply the search, filters, and column choices you want in the file.
2. Select **Export CSV**. The export covers matching entries, not just the visible page, and uses the selected columns.
3. Open the downloaded file and check its headings and sample rows before reporting or sharing. One export contains at most 100,000 matching entries.

### Delete an entry

:::attention
Deletion is permanent in this record list; it has no restore action. Hiding a column is not deletion. Check the entry references before confirming.
:::

1. Use the intended entry's delete action, or select the exact entries for batch deletion.
2. Review the selection and confirmation, then confirm only if removal is intended.
3. Refresh the list and search for the deleted references to check the result.

## What to expect

List preferences change how you review records; they do not redefine the fields collected by your forms. Members see only their own associated records on the member pages your organization makes available.

Deleting an entry is different from hiding a column. Treat deletion as permanent: this record list does not offer a restore action. Supplied record definitions are managed for you; ask support about structural changes rather than trying to change them through a list preference.

## Troubleshooting

- **No results:** clear search and filters, check the selected record type, and return to the first page.
- **A field is missing:** check the column picker. If the field is not offered, contact support about the record definition.
- **A new entry is absent:** confirm that the form submission succeeded and that you are looking at its intended record type.
- **An export is incomplete:** exports are limited to 100,000 matching entries. Narrow the filters and export smaller sets if needed.
