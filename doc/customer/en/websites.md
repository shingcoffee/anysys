## Before you start

The Website module must be enabled for your organization. Sign in as an administrator and look for **Content → Website Pages** and **Settings → Website**. Ask support if the module or site is unavailable.

Prepare approved copy, images, and link destinations. You can edit your site's content and appearance. Supplied page layouts determine section types and order; changing their structure requires support.

## Steps

### Edit a page

1. Open **Content → Website Pages** and select a page to edit. To add one, select **New page**, choose an available layout, enter page details, and select **Create page**.
2. Review the title and slug in page settings. An inner-page slug uses lowercase letters, numbers, and hyphens, such as `about`. Changing it changes that page's address, so update links that use the old address.
3. Edit the words, links, and list items offered in each section. For example, update the opening headline and contact details. Use the page picker for internal links or an `https://` address for an external destination.
4. Add or replace photos where the layout offers them. Upload JPEG, PNG, WebP, or GIF files up to 8 MB, or use an HTTPS image link.
5. Review **Mobile**, **Tablet**, and **Desktop** previews. Check text length, images, and button destinations.
6. Select **Save** and wait for confirmation. Reopen the editor to check the saved copy; an unsaved preview is not a saved page.

### Publish a page and choose navigation visibility

1. Open the page editor's **Page settings**.
2. Select **Published** for a page visitors should be able to open.
3. Select **Show in navigation** only if it should appear in the site menu. For example, an `about` page can be published but omitted from navigation.
4. Select **Save**, then check **Published** in Website Pages and reopen **Page settings** to confirm the saved navigation choice.

:::note
**Save** persists the page's content and settings. **Published** makes that page eligible for public access; **Make site public** opens the site. Both publication settings must be saved. Hiding a navigation item does not protect a published page from direct access.
:::

### Publish the site

1. Open **Settings → Website**. Review the site name, tagline, color mode, accent, font style, spacing, search appearance, footer, and default layout for new pages.
2. Select **Save** to persist the settings. Changing the default layout does not restructure existing pages.
3. In **Publishing**, turn on **Make site public** and select **Save**. Check the saved publication state.

![Unpublished website settings with Make site public switched off and the Save action.](/help/docs/screenshots/en/website-publishing.png "The publication option needs Save; individual pages must also be published before visitors can open them.")

### Check the site as a visitor

1. Return to Website Pages and select **View site**.
2. Open the address in a signed-out browser. Check the home page, menu, footer, and form links.
3. Open the `about` page directly if you published it. Confirm hidden navigation items are absent from the menu while their published addresses remain reachable.
4. If a page is missing, check its saved **Published** choice and the site's saved **Make site public** choice before sharing the address.

### Replace the starter template only when intended

:::attention
Replacement permanently deletes existing pages and sections, resets appearance and the default layout, and discards unsaved settings. Replacement pages are unpublished. Keep needed copy elsewhere before proceeding; this action cannot be undone.
:::

1. In website settings, open **Starter template → Choose a replacement template**.
2. Review its included pages. Select **Replace website** only if you want the replacement described above, and read the confirmation.
3. Check the replacement pages and appearance. Edit, save, and publish the new pages before expecting visitors to open them.

## What to expect

Visitors see published pages while the site is public. Hiding a page from navigation does not prevent access through its address. The home page cannot be deleted. Contact-information sections display details; use a link to an available form when you need submissions.

## Troubleshooting

- **Visitors see a missing page:** check both publishing switches and the current slug.
- **The preview differs from the site:** save edits, then reopen the public page.
- **An image fails:** check its file type, size, or HTTPS address.
- **The layout needs different sections:** contact support with the page name and desired structure.
